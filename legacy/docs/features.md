# VocabLib 機能仕様書

## 概要

VocabLib は macOS のメニューバーに常駐する英単語暗記アプリ。Google Spreadsheet に登録した単語をもとに4択クイズを自動出題し、SuperMemo 2 (SM-2) アルゴリズムに基づく忘却曲線で最適な復習タイミングを管理する。

---

## 1. メニューバー常駐

- アプリはメニューバーアイコン（デフォルト: 📚）として常駐し、Dock やアプリスイッチャーには表示されない（`LSUIElement: true`）
- メニューバーアイコンをクリックするとドロップダウンメニューが開く
- アイコン絵文字は `.env` の `APP_ICON` で変更可能

### メニュー構成

```
📚
├── 今すぐクイズ
├── ─────────────────
├── 自動クイズ: オフ  ← 状態によって表示が変わる
├── 単語を再読み込み
├── ─────────────────
├── 統計: まだクイズに回答していません  ← 状態によって変わる
├── ─────────────────
└── 終了
```

## 2. 単語データソース（Google Spreadsheet）

### シート構成

同一スプレッドシート内に2つのシートを使用する。

#### シート1（ユーザーが手動管理）

| A列（英単語） | B列（日本語訳） |
|---|---|
| apple | りんご |
| study | 勉強する |

- A列・B列のみ使用。ヘッダー行は不要（あっても動作する）
- アプリは読み取り専用で参照し、内容を変更しない
- スプレッドシートIDは `.env` の `GOOGLE_SHEET_ID` で指定
- 読み込み範囲は `GOOGLE_SHEET_RANGE`（デフォルト: `シート1!A:B`）で変更可能

#### 学習記録シート（アプリが自動管理）

| A: word | B: meaning | C: last_reviewed | D: next_review | E: ease_factor | F: interval_days | G: repetitions | H: total_correct | I: example_sentence |
|---|---|---|---|---|---|---|---|---|
| apple | りんご | 2026-03-23T10:00:00+09:00 | 2026-03-24T10:00:00+09:00 | 2.5 | 1.0 | 1 | 3 | The apple rolled off the table and hit the cat. — りんごがテーブルから転がり落ちて猫に当たった。 |

- シート名は `LEARNING_SHEET_NAME`（デフォルト: `学習記録`）で変更可能
- アプリ初回起動時にシートが存在しない場合、ヘッダー行付きで自動作成
- **複合キー**: `word + meaning` で1エントリを一意に識別。同一単語でも意味が異なれば別エントリとして追跡
- スプレッドシートの行挿入・削除・並び替えをしても学習記録がズレない

### Google 認証フロー

1. 初回起動時に `credentials.json`（Google Cloud の OAuth クライアント ID）を参照
2. ブラウザが自動起動し、Google アカウントでの認証を求める
3. 認証後、`token.json` をローカルに保存（以降は自動ログイン）
4. トークン期限切れ時は自動リフレッシュ。リフレッシュ失敗時は再認証

**必要な API スコープ**: `https://www.googleapis.com/auth/spreadsheets`（読み書き）

## 3. クイズ機能

### 3-1. 今すぐクイズ

- メニューの「今すぐクイズ」をクリックすると即座に1問出題
- 自動クイズの ON/OFF に関係なく、いつでも使用可能

### 3-2. 自動クイズ

- メニューの「自動クイズ: オフ」をクリックするとオン/オフを切り替え
- **オン時の動作**:
  - 起動直後に1問表示してから、以降は設定間隔で繰り返し出題
  - メニュー項目が `自動クイズ: N秒後に出題` と残り秒数をリアルタイム表示（1秒ごと更新）
  - カウントダウンが0になると `自動クイズ: 出題中` に変わり、クイズパネルが表示される
  - 回答後はカウントダウンがリセットされ、再び次の出題まで計測開始
- **出題間隔**: `QUIZ_INTERVAL_MINUTES`（デフォルト: 5分）で設定
- **自動開始**: `AUTO_START_QUIZ=true`（デフォルト）の場合、アプリ起動時に自動でオンになる
  - 起動時は最初のカウントダウンのみ開始し、即座には出題しない

### 3-3. 出題単語の選択（忘却曲線）

SM-2 アルゴリズムの `next_review` に基づき、以下の優先順位で出題単語を決定する。

| 優先度 | 条件 | 挙動 |
|--------|------|------|
| 1 | `next_review ≤ 現在時刻` の単語が存在する | 期限超過が最も古い単語を選択 |
| 2 | 学習記録に未登録の単語が存在する | 未学習の単語からランダム選択 |
| 3 | 全単語が学習済みかつ期限前 | `next_review` が最も近い単語を選択 |

### 3-4. 4択クイズ生成

- 正解単語の `meaning`（日本語訳）を正解として使用
- 不正解選択肢（distractor）の生成手順:
  1. スプレッドシートからランダムに4単語を取得（正解単語は除外）
  2. 意味の重複を排除しながら最大3つのdistractorを収集
  3. 3つに満たない場合は「その他の意味 N」で補完
- 全4択をシャッフルし、正解をランダムな位置に挿入

> Ollama を使ったAIによる高精度な distractor 生成にも対応（`generate_quiz_with_ollama`）。現在はローカル生成がデフォルト。

## 4. クイズパネル UI

### 表示仕様

- 画面右下に `360×240` ピクセルのフローティングパネルを表示
- 常に最前面に表示（`NSFloatingWindowLevel`）
- 他のアプリにフォーカスを移してもパネルは消えない（`hidesOnDeactivate: false`）
- 既にパネルが開いている場合は前のパネルを閉じてから新しいパネルを表示

### パネル構成

```
┌─────────────────────────────────────┐
│ VocabLib                        [×] │
├─────────────────────────────────────┤
│ 📚 study                            │  ← 英単語（太字・13pt）
│ 意味を選んでください:                │  ← サブタイトル（11pt）
│                                     │
│ [1. 食べる                        ]  │
│ [2. 勉強する                      ]  │  ← 4択ボタン
│ [3. 走る                          ]  │
│ [4. 眠る                          ]  │
│                                     │
│ [スキップ]                          │  ← スキップボタン
└─────────────────────────────────────┘
```

### 回答後の表示（色付きフィードバック）

選択肢ボタンが即座に以下のように変化する:

- **正解ボタン**: `✅ 2. 勉強する` + 緑色（`NSColor.systemGreenColor()`）
- **選択した不正解ボタン**: `❌ 1. 食べる` + 赤色（`NSColor.systemRedColor()`）
- **その他のボタン**: テキストのみ変更、無効化（クリック不可）

### 不正解時の例文表示（パネル拡張）

不正解時はパネルが下方向に80px拡張（`setFrame:display:animate:` でアニメーション付き）され、例文エリアと「閉じる」ボタンが追加される。パネルの上端位置は変わらない。

```
┌─────────────────────────────────────┐
│ 📚 postpone                         │
│ 意味を選んでください:                │
│                                     │
│ [✅ 1. 〜を延期する               ]  │  ← 緑
│ [❌ 2. 〜を提案する               ]  │  ← 赤
│ [  3. 〜を記録する                ]  │
│ [  4. 〜を許可する                ]  │
│                                     │
│ 💡 He postponed the wedding to      │  ← 例文
│    play games.                      │
│    — 彼はゲームのために結婚式を      │
│      延期した。                      │
│                                     │
│ [スキップ]                [閉じる]  │
└─────────────────────────────────────┘
```

#### 例文の生成・キャッシュ戦略

- **初回不正解時にオンデマンド生成**: Ollama API で短い例文を生成する（5〜10語の映像的・感情的な一文）
- **キャッシュ**: 生成した例文は学習記録シート I列（`example_sentence`）に保存。以降は同じ例文を再利用
- **Ollama 非稼働時のフォールバック**: `"word" means "meaning"` 形式の定型文を使用
- **非同期生成**: Ollama API はバックグラウンドスレッドで呼び出し、生成中は「💡 例文を生成中...」を表示。生成完了後にメインスレッドで UI を更新（`callAfter` 使用）

#### 例文のプロンプト設計（記憶科学ベース）

| 原則 | 理由 |
|------|------|
| 5〜10語の短文 | 一目で読めるため認知負荷が低い |
| 具象的な情景描写 | 映像記憶（視覚エンコーディング）が発動する |
| 驚き・おかしさを含む | 感情を伴う情報は海馬で優先的に長期記憶に転送される |
| 英語 + 和訳の1行形式 | 対訳を同時に見ることで意味の結びつきが強化される |
- 全ボタンが回答後は `setEnabled_(False)` で無効化される

### パネルの自動クローズ

| 結果 | クローズ条件 |
|------|-------------|
| 正解 | 1秒後に自動クローズ（`callLater` 使用） |
| 不正解 | フォーカスが外れたらクローズ（`NSWindowDidResignKeyNotification` 監視）。「閉じる」ボタンでも即時クローズ可能 |

- 正解時のクローズ処理はメインスレッドで実行（`PyObjCTools.AppHelper.callLater` 使用）
- 不正解時はユーザーが例文を読み終えて別ウィンドウをクリック or 別アプリに切り替えた時点でクローズ
- スキップボタンは即座にパネルを閉じる
- パネルクローズ後、自動クイズが ON の場合は次のカウントダウンを再開

## 5. SM-2 スペーシングリピティション

### アルゴリズム

SuperMemo 2 (SM-2) アルゴリズムで次回復習日を計算する。

```
quality = 4（正解） または 1（不正解）

正解時:
  repetitions == 0: interval = 1日
  repetitions == 1: interval = 6日
  repetitions >= 2: interval = 前回interval × ease_factor

不正解時:
  repetitions = 0 にリセット
  interval = INCORRECT_RETRY_MINUTES / 1440 日（デフォルト: 5分後）

EF更新式:
  EF' = max(1.3, EF + 0.1 - (5 - quality) × (0.08 + (5 - quality) × 0.02))
  ※ quality=4 の場合: EF は変化しない
```

### パラメータ

| パラメータ | デフォルト | 説明 |
|---|---|---|
| `INITIAL_EASE_FACTOR` | 2.5 | SM-2 初期難易度係数 |
| `INCORRECT_RETRY_MINUTES` | 5 | 不正解後の再出題間隔（分） |

### 学習記録の更新フロー

1. ユーザーが選択肢を選ぶ → 正誤判定
2. SM-2 で `next_review`, `ease_factor`, `interval_days`, `repetitions` を計算
3. パネルクローズ後にバックグラウンドスレッドで Google Sheets に書き込み（UIをブロックしない）
4. インメモリキャッシュ（`learning_records`）も同時に更新
5. 既存行は `word + meaning` 複合キーで検索して上書き。未登録の単語は新規行を追加

## 6. 統計表示

- メニューに現在セッションの正解率をリアルタイム表示
- 初期状態: `統計: まだクイズに回答していません`
- 1問以上回答後: `統計: 3/5 正解 (60.0%)`
- 統計はアプリ起動中のセッション内のみ保持（再起動でリセット）
- 回答のたびに自動更新

---

## 7. 単語の再読み込み

- メニューの「単語を再読み込み」をクリックで Google Sheets から単語を再取得
- 読み込み開始時に通知バナー表示 `「VocabLib - 単語を読み込み中...」`
- 成功時: `「読み込み完了 - N個の単語を読み込みました」`
- 失敗時: アラートダイアログでエラーを通知

## 8. 設定（`.env` ファイル）

| 変数名 | デフォルト | 説明 |
|---|---|---|
| `GOOGLE_SHEET_ID` | （必須） | スプレッドシートの ID（URL の `/d/` 以降の文字列） |
| `GOOGLE_CREDENTIALS_PATH` | `./credentials.json` | OAuth クライアント認証情報ファイルのパス |
| `GOOGLE_SHEET_RANGE` | `シート1!A:B` | 単語データの読み込み範囲 |
| `LEARNING_SHEET_NAME` | `学習記録` | 学習記録シート名 |
| `QUIZ_INTERVAL_MINUTES` | `5` | 自動クイズの出題間隔（分） |
| `AUTO_START_QUIZ` | `true` | 起動時に自動クイズを開始するか（`true`/`false`/`1`/`yes`/`on`） |
| `INITIAL_EASE_FACTOR` | `2.5` | SM-2 初期難易度係数 |
| `INCORRECT_RETRY_MINUTES` | `5` | 不正解後の再出題間隔（分） |
| `OLLAMA_HOST` | `http://localhost:11434` | Ollama サーバーのホスト URL |
| `OLLAMA_MODEL` | `llama2` | 使用する Ollama モデル名 |
| `APP_ICON` | `📚` | メニューバーに表示する絵文字アイコン |

## 9. PyInstaller アプリバンドル（配布形式）

- `VocabLib.spec` を使って `dist/VocabLib.app` を生成
- ビルドコマンド: `python -m PyInstaller VocabLib.spec --noconfirm`
- `.env` と `credentials.json` をバンドルに同梱
- **ユーザーデータの保存先**: `~/Library/Application Support/VocabLib/`
  - `.env`（ユーザー設定の上書き用）
  - `token.json`（Google 認証トークン）
- バンドル時の設定優先順位: `Application Support/.env` → バンドル内 `.env`

### バンドル設定

| 項目 | 値 |
|---|---|
| バンドル ID | `com.yujikatagi.vocablib` |
| バージョン | `0.1.0` |
| LSUIElement | `true`（メニューバーアプリ） |
| 対応アーキテクチャ | arm64（Apple Silicon） |

## 10. エラーハンドリング

| 状況 | 挙動 |
|---|---|
| Google Sheets API 認証失敗 | `credentials.json` が見つからない旨のエラーログ、`authenticate()` が `false` を返す |
| スプレッドシートにデータなし | エラーログ + `fetch_words()` が `false` を返す |
| クイズ開始時に単語取得失敗 | アラートダイアログ「単語の読み込みに失敗しました」 |
| 学習記録シートが存在しない | ヘッダー行付きで自動作成 |
| トークンリフレッシュ失敗 | 警告ログ + `token.json` を削除して再認証フローへ |
| Ollama サーバー未起動 | `generate_quiz_with_ollama()` が `None` を返し、ローカル生成にフォールバック |
| HTTP エラー（Sheets API） | ステータスコード付きエラーログ |
